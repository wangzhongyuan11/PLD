# 提审与发布（RELEASE）

联调清单（DEPLOY.md 第 6 节）全部通过后再执行。

## 1. 定位与文案（决定审核成败）

- **类目**：工具 > 图像处理/效率类（个人主体可选范围）。
- **措辞红线**：名称、简介、页面文案不得出现"诊断 / 检测 / 医疗 / 病情判断"
  等表述，定位为"**图像分割算法教学演示工具**"。
- 简介参考：`FPGA 图像分割算法的教学演示工具，展示皮肤镜图像、心脏超声与
  心脏 MRI 三种分割流程与指标，供嵌入式教学演示使用。`
- 名称建议备 2~3 个（全平台唯一），如"PLD 分割演示""嵌入式分割课堂"。

## 2. 用户隐私保护指引（提审必查）

mp.weixin.qq.com → 设置 → 服务内容声明 → 用户隐私保护指引：

- 采集的信息勾选：**照片（含摄像头拍摄）**、**保存到相册（相册写入权限）**、
  **选择文件（文件读取）**。
- 采集目的统一填：用于图像分割算法教学演示功能处理与结果展示。
- 小程序端已内置隐私授权弹窗（`components/privacy-guard`，
  `app.json` 已开启 `__usePrivacyCheck__`），无需再改代码。
- 提交指引后等待生效（通常几分钟到 1 小时）。

## 3. 上传与提审

1. 微信开发者工具 → 上传 → 填版本号（如 1.0.0）与备注。
2. mp 后台 → 版本管理 → 开发版本：
   - 先设为**体验版**，发给自己/队友真机回归一遍 DEPLOY 第 6 节。
3. 提交审核：
   - 类目按第 1 节；功能页面截图选"首页 + 任务结果页"。
   - 审核备注可写明："本小程序为嵌入式课程 FPGA 图像分割教学演示，
     需连接实验室开发板（桥接常驻电脑在线时可用）；审核时段可能无法
     连接板卡，结果页交互见体验视频/截图。"建议附一段演示录屏链接。
4. 审核通过 → 全量发布。

## 4. 发布后运维

- 板卡/桥接可用性直接决定用户体验；桥接电脑保持开机。
- 云开发套餐与流量在控制台监控；单任务往返约 5~15MB。
- 小程序下架/停用不影响板卡任何现有功能。
