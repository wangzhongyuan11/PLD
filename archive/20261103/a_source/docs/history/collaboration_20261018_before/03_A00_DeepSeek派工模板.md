# DeepSeek 执行助手派工模板

由 Codex 填入必要字段后交给 dsh；删除无关字段，不重复附上完整聊天。协作责任与授权边界以项目根目录 `AGENTS.md` 为准。

```text
你是本竞赛项目的执行助手。完成下面已审查的任务，将证据保存在项目内；不自行扩展任务，不修改用户全局配置，不读取/输出私人密钥或配置。

目标：<一个可检验的结果>
输入：<必要文件路径；获准下载来源或图片清单；必要背景>
允许范围：<工作目录、可读写路径、批准的工具/命令>
步骤：<简短动作；能用脚本批量做的批量做>
验收：<成功条件、指定检查、证据文件；图片任务需记录实际视觉依据与不确定项>
需 Codex 裁定：<助手只能给证据/建议、不能擅自决定的事项；低风险任务可省略>
预算：<样本/文件范围、预计新增与峰值占用、适当运行预算；项目总量不得超约40GB，含环境、缓存及临时峰值>
停止条件：<超范围/超预算、权限拦截、图像不可见、输入不符或重复失败；保留进度并报告>
断点：<阶段保存路径与恢复方式；收到 Codex 的额度保护通知后停止新增工作，在安全步骤结束后保存并停止>
状态回报：<启动/里程碑/异常/完成时给短摘要和证据路径；不变不重复分析，完整日志落盘>
交付：<产物与日志路径；执行摘要；通过/失败/未完成项；必要的下载来源、数量、字节和校验记录>

不输出长篇思维过程，不反复复述要求，不扫描无关目录。不将自评当作最终验收，Codex 会核查产物及证据。
```

图片初审：提供具体 ID 和判定规则，要求逐项短结论与可复查的图片证据；明确当前是否真正看到了图片。含糊案例保留待复核，不自行删除原图或改变数据划分。

下载：使用 Codex 已批准的清单，复用已有文件，支持中断后校验续传，记录失败/跳过项和完整性；禁止把部分完成记为完整数据集。

派工前按 `A01_助手职责与高级工程师审查.md` 选择执行范围和复核强度。Codex 负责查询自己的账户额度，助手不得读取用户账户或密钥来代查；Codex 任一相关额度窗口剩余 ≤7% 时启动保护，按 `A03_额度保护与断点恢复.md` 收尾。
