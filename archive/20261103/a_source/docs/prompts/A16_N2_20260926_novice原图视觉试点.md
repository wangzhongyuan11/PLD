# A16-N2：Novice 新病例原图、掩膜配对与视觉质量试点

执行者：DeepSeek 主执行（下载、代码、拼图、统计）；Codex 负责看图与最终样本裁定。仅在 A16-N1 的微小病灶抽样修正经 Codex 验收后启动，不自行进入训练。

## 输入与目标

- 使用 `runs/role_a_a16_novice_mask_audit/pilot_selection.csv` **修订版** 48 个 ID：至少 16 张位于非空非满掩膜面积最小 10%；检查清单与 ZIP/mapping/metadata 一致，先记录清单哈希。
- 官方 Archive API：`GET https://api.isic-archive.com/api/v2/images/<ISIC_ID>/` 取得 `files.full.url`；只获取该 48 张原图。复用已下载的官方 `Masks.zip`，按 mapping 白名单内读取对应 48 张掩膜。保留数据来源、每图许可和 ViDIR 归属。
- 目标是确定图和掩膜是否配对、质量是否足以尝试后续训练，及是否与旧训练/开发/最终留出图视觉重复。试点结论不依赖开发集 Dice，不把 novice 掩膜视为无误真值。

## 分阶段执行

1. 先做 2 张非异常样本冒烟：API ID/URL/许可、原图尺寸与文件格式、掩膜 600×450、宽高比差异、二值性、缩放后配准与回读检查。原图和 mask 不同尺寸是已知事实，**不得沿用 A15-D0 的“原始尺寸必须相同”断言**；只在宽高比差≤1%时将图像按 LANCZOS 缩至 600×450，掩膜保持原样。超出则隔离标记待 Codex 看图，不强行拉伸或默默丢弃。
2. 冒烟通过后只下载这 48 张，原始 JPG 以独立 `.part` 落盘，核对完成和 SHA256 后再原子改名；每 URL 有总超时/低速终止，最多一次重试，先检查官方 API 的 `files.full.size` 与峰值预算。保存规范化图像与 48 张对应掩膜在 `data/raw/isic2018_novice_pilot/{images,masks}/`；保留原始文件或其哈希/下载字节证据，不能以重编码后 SHA 当原图 SHA。只清理能确认属于本任务的临时文件。
3. 核对每对图像/掩膜尺寸、掩膜取值、metadata ID、掩膜面积比例。生成逐图「原图 / 半透明轮廓叠加 / 二值掩膜」视觉对照页，按面积组分组，页数与字体保证 Codex 能读清每张 ISIC ID；DeepSeek 没有看图能力时只写像素级初审，**不冒充视觉判断**。明确呈现 16 张真正底部10%小病灶样本。
4. 对 48 张原始图像计算 SHA256、dHash，按 ID/哈希/dHash≤4 与项目内 train2309、dev638、final test1000 **仅图像**逐项筛查；对可疑近重复生成双方图像并排页交 Codex 视觉核对。与试点内部也做重复筛查。dHash 是筛查线索，不自动判为同病人；缺 patient_id 的风险继续标未知。最终测试掩膜始终不打开。
5. 输出 `runs/role_a_a16_novice_image_pilot/REPORT.md`、`pair_audit.json`、`overlap_screen.json`、对照页、下载台账、真实退出码/异常记录、峰值与持久字节、恢复入口；更新 `docs/A02_当前断点.md`。停下等 Codex 视觉复核与是否进行训练的裁定。

## 资源和边界

仅官方源，竞赛非商用用途，保留 CC-BY-NC 和归属。新增持久目标 <250 MB，临时峰值 <450 MB，项目总量 <40 GB（2026-09-26 用户调整）；如 API 显示 48 张将超此试点预算，先报告并停，不悄悄缩水样本数。无新依赖、全局配置改动、旧模型替换或训练。长步骤按阶段落盘，少量短状态，不无意义轮询。
