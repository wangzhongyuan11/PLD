# A11：v4 INT8 掩膜后处理试验（DeepSeek 执行）

先读本项目 `AGENTS.md` 与 `docs/A02_当前断点.md`。Codex 已确认 A10 的 v5 INT8 总体 Dice 0.8399490473 低于 v4 的 0.8406329361；本任务只针对**现有最佳 v4 INT8**，试一个无需改变 FPGA CNN 网络或重新训练的轻量后处理。Codex 最终裁定是否采用。

## 固定输入与规则

- 模型：`runs/role_a_overall_v4_dice2_base8/best.pt` 与 `runs/role_a_overall_v4_dice2_base8/int8_overall96/model_spec.json`。先核对现有 `comparison.json` 的 638 张 INT8 总体 Dice 为 0.840632936148671、阈值 0.45、开发集身份哈希和校准来源。不可修改这些输入。
- 在冻结的同一 638 张开发集上，用 v4 **INT8 软件模型**生成阈值固定为 0.45 的二值掩膜；验证样本不进入训练或量化校准。只在 letterbox 的 `valid` 区域内处理，invalid 像素永远为背景。
- 预先限定四种候选：①原样（identity）；②填充前景内部封闭空洞（fill holes）；③只保留最大 8 连通前景分量（largest component）；④先保留最大分量再填洞。填洞以 4 连通背景判断是否接触有效区域边缘，接触者不填。预测为空时均保持为空；最大分量并列时使用固定的最靠上、再最靠左规则。不按开发集结果临时增加阈值、最小面积或按图自适应条件。
- 每种候选对全部图像使用**同一规则**，选模仍以 638 张逐图平均 Dice 最大为主，完全相同则优先 identity、fill holes、largest component、combined 的顺序。固定面积组与来源统计，并记录每图变化、运行耗时。该方案只增加 ARM/PS 端掩膜处理；报告算法最坏复杂度、临时内存和桌面实测耗时，说明未做真实 PYNQ-Z2 时序测量。

## 实现与核验

- 代码写 `software/role_a/postprocess_int8.py`，针对性测试写 `software/role_a/tests/test_postprocess_int8.py`，结果和日志写入新目录 `runs/role_a_v4_postprocess_a11/`。不改训练器、模型、量化器、旧 run 或数据。优先用现有 NumPy/Pillow/PyTorch 与标准库；不安装新依赖，不下载数据。可复用量化加载、冻结装配及面积分组函数，避免重抄指标定义。
- 必须先在同 638 张图、同 0.45 阈值下复现**原样 v4 INT8** 的 0.840632936148671（容差 ≤1e-9），且每来源数量与既有记录一致；不匹配立即停止，不在不一致口径上继续比较。
- 单元测试覆盖四连通/八连通区别、对角连接、等面积并列、内部空洞与开放缺口、valid 补边、空预测、与原样相同的无变化图、每图 Dice/IoU 汇总；做一个小型合成样本的人工真值检查。审查测试不是仅重复实现调用。
- 完成后提供四候选的总体 Dice/IoU、三来源、三面积组、相对原样差值、多少张变好/变差/不变及最坏退步个例 ID，连同阈值、模型/spec/代码哈希。若四者无一个优于原样，就明确维持 v4 原包，不自动启用后处理。保存逐图短记录与日志，但对话只回传结论与路径。
