# A16-N1：官方 Novice 分割掩膜归档与试点清单

执行者：DeepSeek 主执行。仅在 Codex 审查并放行 A16-N0 修订后开始。目标是审查新标注源的完整性与质量分布，**本阶段不下载原图、不训练**。

## 已审来源与输入

- 官方页面：`https://api.isic-archive.com/doi/isic-2018-novice-segmentation-masks/`；该页直接链接的 PNG 掩膜包：`https://isic-archive.s3.amazonaws.com/dois/10.34970-387951/supplements/Masks.zip`，标称 19.1 MB，CC-BY-NC，ViDIR Group 归属。
- 复用已校验的 metadata/mapping CSV、固定 train2309/dev638/final test1000 图像 ID 清单与 A16-N0 修订报告。先复核 mapping 的 11,720 ID 与这些集合精确交集 0，并核实参考病灶编号覆盖率；`patient_id` 未知要继续标未知。
- 不读取任何 2018 最终测试掩膜，不修改旧模型、划分或交付。

## 执行边界

1. 只下载上述 `Masks.zip` 到 `data/raw/isic2018_novice_pilot/`，单 URL 最多 1 次重试；设置总超时、低速终止，并尽可能断点续传。记录每次尝试、最终字节数、SHA256、服务器长度与 ZIP CRC 结果。下载异常停下，不换第三方镜像。
2. **读取 PNG 前**先仅看 ZIP 目录：拒绝绝对路径、`..` 穿越、符号链接、重复条目、非 PNG；核实 ZIP 每条都在 mapping 中、mapping 每条恰好对应 1 条 ZIP 项，并再次排除 final test/dev ID。若条目名有安全的单层目录前缀，可以正规化后比较，但记录实际格式；不能因数目相等就跳过逐项核验。
3. 确认安全后，在内存逐条读取掩膜，不全部解压到磁盘。逐条检查可解码、尺寸、颜色通道、有效像素值、空/满掩膜、面积比例，得到全量直方图与异常 ID 清单；尤其核对 `ISIC_0035068` 空掩膜。不要假设标注完全正确，也不要将未经图像视觉审核的掩膜直接并入训练。
4. 在排除明显异常掩膜后，按面积比例的低/中/高段、解剖部位与诊断元数据确定性抽样约 48 张用于下一阶段原图质量试点；微小面积段至少 16 张。只生成 **ID 清单和抽样理由**，本阶段不下载这些原图。抽样不依赖开发集 Dice 或最终测试集表现。
5. 输出 `runs/role_a_a16_novice_mask_audit/REPORT.md`、可机读 `zip_manifest.json`、`mask_qc.csv`、`pilot_selection.csv`、下载台账和简短错误日志。给出有效/异常数量、大小字节、峰值空间、代码哈希与复现命令；报告质量局限和下阶段需人工视觉复核。完成后停下待 Codex 裁定。
