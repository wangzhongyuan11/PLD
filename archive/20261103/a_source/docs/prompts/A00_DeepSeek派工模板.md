# 双主执行任务单

适用于双方模块交接；保留这个旧文件名供现有链接使用。按任务填入必要字段，删除无关项，不附全量聊天。模式和授权以项目 `AGENTS.md` 为准。

```text
任务ID/阶段：<唯一ID；本批完成后返回，不能自开下一轮>
负责人/复核方：<Codex或DeepSeek；各一名>
目标：<一个可验收的模块或阶段>
输入与合同：<必要路径、版本/SHA、前置产物；使用当前AGENTS和断点>
范围与所有权：<可改文件/目录；唯一控制的进程/资源；明确共享冻结项>
自主决策：<本范围内可自行选择的方法；需交回判断的合同/指标变更>
预算与停止：<有限工作量/阶段、运行/停滞上限、重试与必要往返；已知费用预算；达标即停，无新信息或超限则重规划>
验收：<真实成功条件、针对性检查、失败判据>
交付/恢复：<产物、短STATUS、日志；断点、启动身份与安全停止办法>
回报：一次汇总完成项、结果、证据、实际可得的消耗、异常/未完成；只有必要时提出下一步，不另发付费确认。
```

- 范围足够清楚时直接做实现、测试和修复，不逐步索要批准。跨模块改合同、改变冻结划分/门槛或越界时停在该边界，继续其他独立工作。
- 重复统计、下载和校验交给脚本批量执行；图片必须实际可见，报告样本ID、观察与不确定项。视觉观察不能代替数值评价或决定临床结论。
- 开始前核对文件/进程所有权；完成后提供身份、退出码、检查结果与剩余风险。不要将“已经准备脚本”写成“已执行通过”。
- 付费调用记录实际可得的模型标识、输入/输出/缓存命中及费用；不能取得则写未知。需要图像时只给足够判断的样本/裁剪，必要细节保留原分辨率。
- Codex维护总断点；执行方只更新任务自己的状态。没有自动成本统计或停止能力时明确说明，不声称已安装。
