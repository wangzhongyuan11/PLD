# 数据与实验规范

## 数据登记

主数据候选为 ISIC 2016 Task 1，官方入口：https://challenge.isic-archive.com/landing/2016/37/ 。暂未下载。
赛题截图提及 CC-0；实际使用前仍需保存具体下载包对应的许可/条款和引用要求，不能将整个 ISIC 平台一概视作相同许可。

下载后记录：数据版本、来源 URL、获取日期、许可证据文件、文件 SHA256、图像/掩膜配对、患者或病灶标识可用情况。不得把无标注的图像假装成有测试真值。
原始数据保持不变，放入 `data/raw/`，转换结果单独放在 `data/processed/`。

## 划分

900 张官方训练图像中划出固定验证集，暂考虑约 80%/20%；若存在患者/病灶组信息则按组划分。缺少组信息时记录限制，不声称完全排除患者级泄漏。
官方 379 张测试图像用于最终评估；先确认测试标注当前是否可获取。若不可获取，使用预先冻结的内部测试划分并如实命名，不能称为官方测试分数。
不能看测试结果反复选参数。增强、裁剪和补丁均须在划分之后生成，不能让同一原图的不同版本跨集合。

## 预处理

先做保持比例缩放到 256×256 内，再补边；记录有效区域和原始尺寸。掩膜用最近邻缩放，图像可用双线性缩放。
第一版可以在缩放后的有效区域评估，但报告必须注明评估空间；正式与公开结果比较时应恢复到原始尺寸并按相同评估协议计算。
不能用同一标注自动生成阈值再在该图上报告“独立测试”。

## 指标与实验分组

- 逐图计算 Dice/IoU，再报告平均值、中位数及失败例；空预测与空真值的处理规则需明确。
- 对照：固定阈值；滤波+阈值；滤波+阈值+形态学；后续自动阈值；增强阶段的浮点/INT8。
- 保持划分、图像尺寸、参数选择策略相同。交互手调结果与全自动结果分开报告。
- 记录端到端、传输、硬件计算时间；预热方式、重复次数、软硬件版本一并保存。
- 同类方案比较需核对数据版本和指标协议，不能直接比较不同条件下的数字。
- 当前合成示例只做功能验证，不能写入“医学精度已达到”或“硬件加速比”。
