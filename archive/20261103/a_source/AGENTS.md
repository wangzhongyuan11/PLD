# A 组持久协作规则

仅适用于 `E:\嵌赛\pld-medical` 及明确相关的 PLD 任务；用户最新指令优先，不推广至其他项目或全局配置。共享边界遵循仓库根 `AGENTS.md`。

## 执行模式

**默认：ChatGPT/Codex 与 DeepSeek 共同主执行。** 新对话直接沿用，不重复询问。保留以下三种模式；单次切换仅影响本轮，除非用户要求修改默认。

| 模式 | 执行责任 |
|---|---|
| 共同主执行（默认） | Codex 主责科研判断、实验/数值合同、关键后端、跨模块集成及最终验收；DeepSeek 主责可独立验收的工程模块、长程自动化、已冻结训练/评估流程、视觉图表与交付整理。双方可在各自范围内设计、实现、测试和修复，不逐条等对方批准。 |
| Codex 主执行 | Codex 承担主要设计、实现、集成和验收；DeepSeek 仅做方法固定的简单重复工作。 |
| DeepSeek 主执行 | DeepSeek 承担主要工程与有界流程执行；Codex 负责目标、关键合同、科研/复杂问题、阶段审查和最终验收。 |

- 分工是可调整的项目策略，不把模型品牌或宣传当作能力证明。DeepSeek 目标版本为 **V4.1-Flash-1017**，实际服务版本以可取得的 UI/API 证据为准；不得静默换模型。科研/后端也可拆出有验收条件的模块交给 DeepSeek，避免所有实现都堵在 Codex。
- **同一文件、进程、GPU 队列、设备和交付版本只有一个写入/控制负责人。** 独立模块才并行；共享接口先冻结，交接附版本和证据。Codex 负责维护当前总断点与整合结论，DeepSeek 写自己的任务状态；不得互相派回同一任务形成循环。
- 每个任务只需目标、输入/合同版本、可写范围、负责人、预算/停止条件、产物/验收。已有授权内自行推进；变更冻结指标/数据划分/接口、扩大权限或发布范围时先交 Codex 判断，越出用户授权才询问用户。
- 已建立的 dsh 项目会话优先复用。连接或能力不足时记录原因，可由另一方接手可验证模块；不暗中扩大权限或假称双执行已运行。详细协议仅在派工或冲突时读 [A01](docs/prompts/A01_助手职责与高级工程师审查.md)。

## 效果、资源与费用

- **质量验收是硬约束；满足相同要求时，默认选择预期总成本最低的可靠方案。** 成本计入双方输入/输出、工具调用、监督、返工与交接，不只比较单次token或模型单价。先复用成熟成果和有效证据，再用脚本；只有需要判断时调用模型，不为省钱降低数据、精度、复现或验证标准。
- **共同主执行不要求每项任务双方都参与。** 小任务由当前负责人直接闭环；只有能增加有效产出或发现不同错误时才交接/交叉审查。按完整模块批量派工、一次交付，取消纯确认、重复解释及无变化轮询；常规验证自动执行，关键数据隔离、量化、指标、模型替换与发布仍由 Codex 独立核验关键证据。
- 付费批次先限定工作量、阶段/时间和重试；默认不增加 agent 或付费并发。同因失败两次即停下定位/换方法，不能反复微改碰运气。只记录可得的实际消耗和费用；未知标未知，不按账户百分比估算。投入超预期、证据已足够或继续尝试无新信息时及时结束/重规划；确需更多投入以达标时给足资源。具体做法见 A01。
- dsh 在已授权项目内可读取必要代码、数据、权重/断点并写任务产物；不得读取或输出密钥、改全局配置、上传到无关服务。新增付费服务、充值、超预算、项目外写入或不可恢复删除需明确授权，既有批准不重复问。
- 项目峰值上限 **40,000,000,000 B**，包含环境、缓存、压缩/展开副本、检查点和临时文件。删除前核对准确路径、恢复来源及保护清单；保留唯一模型、恢复状态、划分、许可与证据。

## 数据与验收

- 固定数据角色、划分、种子、主指标与选模/阈值规则；调参用过的集合标记为开发集。封存测试集须有对应版本的一次性明确授权，旧模型许可不继承给新候选。
- 模型效果和计算/存储/算子预算同时评估；软件精度、整数参考、仿真、真实上板及端到端性能分层报告。核对实际产物、退出码、哈希与指标，明确计划/已执行/已验证/未完成。
- 皮损、CAMUS、ACDC 按各自冻结合同和验收门槛执行，不把旧皮损目标套到 MRI。新任务门槛先定后看结果，失败保留证据，不降低门槛凑通过。皮损历史约束及验收方式按需见 A01。
- 根 `delivery/current.json`、旧正式模型和已关闭许可保护；A 的 Git 共享范围与 Release 方式按根规则。解决审查意见后，以当前提交的复审及匹配验证作为发布/合并依据。

## 最小上下文与保护

- 恢复先读 [当前断点](docs/A02_当前断点.md)，再查当前任务的一份短状态和必要证据。`AGENTS.md` 只写长期规则；断点只保留当前事实和下一步；旧内容归档，链接按需读取。
- 传路径、版本和增量结论，完整日志/逐图指标落盘；同一未变文件本轮不反复读取。短回报用“完成/结果/证据/异常/下一步”，篇幅以足够判断为准，不截断关键证据。
- 每个长任务只设一方监控，优先脚本、阶段事件及异常；不让双方轮询同一进程。无变化不触发模型分析，不为维持进度另建定时唤醒。
- Codex 任一相关额度剩余 **≤10%** 进入收尾，**≤7%** 立即安全保存并停止新工作；DeepSeek 同样受任务预算/停止条件约束。不能通过交给另一方无限续跑绕过保护。实际检查、租约和恢复流程见 [A03](docs/prompts/A03_额度保护与断点恢复.md)。

按需：派工用 [A00](docs/prompts/A00_DeepSeek派工模板.md)；双主执行与审查用 A01；额度保护用 A03；模型能力/价格核查见 [2026-10-18 依据](docs/prompts/DEEPSEEK_1017_依据与成本_20261018.md)。不默认加载整套文件。
