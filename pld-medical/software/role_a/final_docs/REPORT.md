从 soup 出发、输入/权重/输出三处假量化（STE、与部署同规则）、96 张 FP32 直通校准尺度、第 4 轮后同批重算一次、8 轮常数 lr 3e-5。

## 4. 假量化代理 vs 真实 INT8 的一致性（638 张逐图，仅 soup）

数据来自本包 `metrics/a21_consistency_638.json`（对 soup 完整重算，**不是** 8 张探索版）。

| 指标 | 值 | 口径 |
|---|---|---|
| 逐像素平均绝对概率差（整张 256×256，含 letterbox 补边） | 0.005316067746609411 | 每图全图逐像素平均，再对 638 张取平均 |
| 逐像素平均绝对概率差（**仅 valid 区域**） | 0.007337944277746130 | 每图仅非补边像素，再对 638 张取平均 |
| 逐图最大值：均值 / 最大 / p95 | 0.4367437836798755 / 0.7478451132774353 / 0.6303386688232422 | 每图最大绝对差 |
| 阈值 0.45 翻转像素比例最大 | 0.042826334635416664 | 相对 valid 像素 |
| **逐图 signed Dice 差（fake − real）均值** | **−0.00045516174411766054** | 阈值 0.45，638 张 |
| 逐图 Dice 差的绝对值：均值 / 最大 | 0.0035249525371000155 / 0.20799560379172966 | 阈值 0.45 |
| 逐图 Dice 差 >0.001 的图数 | 391 / 638 | 阈值 0.45 |

**解读**：代理与真实 INT8 的**整体 signed Dice 差为 −0.00046**（代理略偏悲观），但**单图并不等价**（平均绝对差 0.00352，61% 的图差 >0.001，最坏 0.208）。因此 A21 选点始终以**真实 INT8 的 dev638 Dice** 为准，未用代理选点。
（阶段 0 另有一个实验测得"仅激活量化 + FP32 权重 vs 真 INT8"的总体 Dice 差 = 0.0000994；那是**不同对象**，与本节的完整 QAT 假量化代理不可混用。）

## 5. 复现步骤

```powershell
# 0) 环境前提
#    - 在仓库根目录 E:\嵌赛\pld-medical 下执行（模块路径 software.role_a.* 才能导入）
#    - 全程使用项目虚拟环境（Python 3.12.14 / torch 2.11.0+cu128；仅复现指标与校验用 CPU 即可）
$py = '.\.venv\Scripts\python.exe'

# 1) 核验最终模型与 INT8 产物（15/15 层黄金向量）
& $py -m software.role_a.verify_export `
        --spec deliverables/role_a_final/int8/model_spec.json `
        --output-json runs/verify_final.json

# 2) 复现 dev638 指标（一次评估同时给出 FP32 + INT8 五阈值）
& $py -m software.role_a.evaluate_quant_overall `
        --checkpoint deliverables/role_a_final/best.pt `
        --spec deliverables/role_a_final/int8/model_spec.json `
        --output-dir runs/reproduce_final

# 3) 复现 638 逐图代理一致性
& $py software/role_a/a21_consistency_638.py `
        --candidate deliverables/role_a_final/best.pt `
        --spec deliverables/role_a_final/int8/model_spec.json `
        --output runs/reproduce_a21_consistency.json

# 4) 复现 A21 负结果（约 63 分钟；需要 GPU）
#    必须使用**新的空输出目录**（下例 runs/reproduce_a21_qat8）；
#    切勿指向已保存的正式训练目录 runs/role_a_final_qat8，否则会覆盖其 latest.pt 与逐轮产物。
& $py -m software.role_a.final_qat_driver --output-dir runs/reproduce_a21_qat8 `
        --epochs 8 --lr 3e-5 --batch-size 4 --seed 20260926 --device cuda --num-workers 2

# 5) 重新生成交付包（目标路径在脚本内被硬性限制为 deliverables/role_a_final）
& $py -m software.role_a.a21_build_package
```
