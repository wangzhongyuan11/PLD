## 性能目标的适用范围

- 30 帧/秒：暂定基础 FPGA 计算链目标，不含传输，不适用于尚未设计的神经网络。
- 200 毫秒：图像已在板端缓存后，从参数请求到界面完成更新的目标；包括结果回传。
- Dice≥0.85：增强版研究目标，不是已知可达值；软件基线后复审。
- 量化损失≤0.02：同一数据划分、同一预处理下的平均 Dice 绝对差。
- 功耗与加速比：不预填数字；记录测试平台、频率、计时边界。不能用当前纯 Python 教学实现证明 FPGA 相对优化 CPU 的优势。

## 完成门槛

基础闭环通过后才启动神经网络上板；软件正确不等于 RTL 正确，仿真通过不等于时序通过，综合通过不等于板级稳定。
每项完成记录必须带日期、配置、输入、输出和证据路径。
