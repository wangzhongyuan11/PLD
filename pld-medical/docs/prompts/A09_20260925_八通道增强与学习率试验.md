# A09：8 通道增强与学习率试验（DeepSeek 执行任务书）

你是本项目 dsh 对话中的执行助手。先读 `AGENTS.md` 和 `docs/A02_当前断点.md`，只回传简短状态与证据路径。Codex 负责实验设计、代码审查、量化验收和最终选模。

## 目标与固定口径

在现有最佳 8 通道 v4 权重上，尝试**只在训练时**加入同步 90 度整数旋转，并使用按轮次变化的余弦学习率。部署网络、256×256 输入、2309 张冻结训练集、638 张冻结开发集、五个统一阈值、逐图平均 Dice 选模规则保持不变。微小/中等/大面积组及三个来源都需报告；优先选择总体 Dice 更高、且 INT8 软件复核通过的候选。不用 2018 验证集或最终留出集训练/调参，不读取 2018 最终测试掩膜。

起点 `runs/role_a_overall_v4_dice2_base8/best.pt` 的 SHA256 必须为 `65bb913162812ae602aa6ce0f6cda183eb9f8e706af3a1b15a572e7159151b63`；起点 FP32 总体 Dice 0.8431070098、INT8 总体 Dice 0.8406329361、统一阈值 0.45。训练阶段的计划参数：8 通道、batch 4、Adam、BCE 权重 1、soft Dice 权重 2、梯度裁剪 5、种子沿用现有训练器，最多 12 轮；初始学习率 0.0001，按轮余弦降至 0.000005，无重启。每张图按确定性种子独立取 0/90/180/270 度旋转，图像、mask、valid 同步；原水平/垂直翻转及轻量亮度/对比度增强保留。验证/量化校准预处理绝不旋转。

这是一个整体训练方案，若改善，不能将改善单独归因于旋转或学习率。不要在试验途中看指标改配置。若实现发现上述设定有不可兼容或明显质量问题，先暂停并用短证据说明，由 Codex 裁定。

## 阶段一：代码与可恢复性（审查后才启动训练）

- 可读取本项目既有训练器、测试、数据及断点。新代码写入 `software/role_a/train_overall_v2.py`、必要的针对性测试写入 `software/role_a/tests/`，不要改写 `train_overall_v1.py`、旧 run 目录或旧数据。优先复用 v1 的数据装配、指标、模型与检查点工具，避免复制整个 2000 行文件；也不要靠运行时 monkey-patch 全局函数实现关键行为。
- 新训练器必须按轮保存 `latest.pt`（模型、优化器、随机状态、当前学习率/调度状态、历史、配置/输入/代码哈希），训练后但评估前中断不得重复同轮梯度更新。`--resume` 必须拒绝不同配置/代码/输入哈希、缺失断点及已完成试验；输出目录不得覆盖旧实验。保持 `best.pt` 与 `completed.json` 语义。训练及验证读入只限冻结清单；验证集不得进入反向传播。
- 使用明确的整数旋转，证明正方形 letterbox 后 image/mask/valid 逐像素对齐、前景不落在 invalid 区、每轮每图随机参数不随 worker 调度改变。学习率日志记录每轮实际使用值；恢复与不中断运行在相同环境下应得到相同轮次序列。避免任何增加上板算子的改动。
- 至少做小型合成样本的增强对齐测试、学习率边界测试、训练后评估前恢复测试、配置/输入哈希拒绝测试、旧模型形状/算子白名单检查。真实数据只做装配 dry-run 和起点权重/目录/空间核验。先将测试结果、关键代码差异、拟运行命令与峰值空间估计交 Codex 审查；**收到 Codex 明确放行前不启动完整训练**。
