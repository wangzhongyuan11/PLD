# ACDC 三方向 2.5D：板端无模型预适配规格

| 项目 | 内容 |
| --- | --- |
| 规格标识 | `ACDC25D-B16-P3-v1` |
| 文档日期 | 2026-10-17（北京时间） |
| 当前状态 | **2026-10-19：三方向模型训练、原生开发集FP32/INT8、融合及整数软件验收已完成；参数身份见[研究交付索引](RESEARCH_RELEASE.json)。物理CAM2板端验收仍未完成** |
| 目标 | 三方向 INT8 推理优先部署到 PYNQ-Z2；PC 负责体数据预处理、坐标恢复、概率融合及三维重建 |
| 使用方 | A 组模型与量化、B 组板端实现、C 组或 PC 侧集成 |

本文汇总冻结的结构和数值接口，供加载器、调度、DMA 和 PC 对接；无模型合成预适配用例仍保留。后续若改变层数、通道、尺寸、类别或 CAT 语义，必须显式升版本并同步适配方。

用户现已明确指示按计划表和本规格编程及训练。本文作为冻结的结构和数值设计原则；执行进度、数据问题与验收分别记录，不能把接口容量证明或软件模拟当成真实板端验收。

## 1. 总体结构

- 三个方向：轴向 `axial`、冠状 `coronal`、矢状 `sagittal`。
- 模型 ID 分别为 `acdc_axial_v1`、`acdc_coronal_v1`、`acdc_sagittal_v1`。
- 三个方向使用完全相同的网络拓扑，各自训练和加载一套权重与量化参数。
- 每次请求运行所选方向的一套网络，预测一张中心层的四通道 head。
- 优先复用一套计算结构，依次切换三套模型参数；不预设同时放置三套硬件网络。
- 每个方向 **15 个卷积层、3 次 MaxPool、3 次最近邻上采样和 CAT**。
- ReLU 融入前 14 个卷积；上采样、两路尺度转换与 CAT 由一个融合节点完成，因此调度图为 **21 个逻辑算子节点**。
- 逻辑节点数不等于硬件命令数。空间 tile、输出通道分块、参数与 LUT 装载均会增加命令数。

## 2. 固定输入和输出

### 2.1 输入

| 项目 | 规定 |
| --- | --- |
| 类型 | 有符号 INT8，合法值 `[-127,127]`，不使用 `-128` |
| 形状 | `[N,C,H,W] = [1,3,256,256]` |
| 布局 | 连续 NCHW；W 最快、然后 H、然后 C；batch 固定为 1 |
| C0 | 同一方向的前一层 |
| C1 | 同一方向的中心层 |
| C2 | 同一方向的后一层 |
| 边界 | 邻层索引越界时，重复最近有效层 |
| 量化 | `q = clip(round_even(127*x), -127, 127)`，其中到板端接口前的归一化张量 `x∈[-1,1]` |
| 输入 scale / zero_point | `1/127` / `0`；三个输入通道共用同一 scale |
| 完整输入长度 | **196,608 B = 192 KiB** |

NCHW 连续缓冲区的元素偏移为：

```text
offset(n,c,y,x) = ((n*C + c)*H + y)*W + x
```

MRI 读取、体数据强度标准化、方向重排、空间重采样和尺寸处理在 PC 侧实现并记录参数。板端接收已量化张量。MRI 原始强度并不等同于 `[-1,1]`；强度归一化实现须在训练前与输入协议一并冻结。

三个通道是同一方向的空间邻层，不是 RGB，也不是将轴、冠、矢三个切面直接拼成三个通道。ED/ES 是时相，不作为这三个空间邻层通道。

### 2.2 输出

| 项目 | 规定 |
| --- | --- |
| 类型 | 有符号 INT8，合法值 `[-127,127]` |
| 形状 | `[1,4,256,256]` |
| 布局 | 连续 NCHW |
| 含义 | 中心层四类量化 logits |
| 完整输出长度 | **262,144 B = 256 KiB** |
| 输出头激活 | 无 ReLU、Sigmoid 或 Softmax |
| head scale | 同一个方向模型的四个通道共用一个正 `head_scale` |
| head zero_point | 固定为 `0` |
| 反量化 | `head_float = head_int8.astype(float32) * head_scale` |

类别与颜色固定如下：

| 通道 / 标签 | 名称 | 显示颜色 |
| --- | --- | --- |
| 0 | 背景 | 黑 / 透明 |
| 1 | 右心室腔 RV | 红 |
| 2 | 左心室心肌 MYO | 绿 |
| 3 | 左心室腔 LV | 蓝 |

原始标签保持 `0/1/2/3`；彩色图只用于展示。该类别协议与旧 CAMUS 协议不同。

三个方向的 `head_scale` 可以不同。真实数值训练和量化后由各自 `model_spec.json` 提供，**不得填写或沿用旧 CAMUS 的 scale**。PC 对各方向先反量化、转换为概率并恢复空间坐标，再融合；不能直接平均不同尺度的 INT8 head。

## 3. 固定算子定义

| 算子 | v1 规定 |
| --- | --- |
| C01～C14 | `Conv2d + ReLU`，3×3，stride=1，padding=1，dilation=1，groups=1，带 bias |
| C15 | `Conv2d`，1×1，stride=1，padding=0，dilation=1，groups=1，带 bias，无 ReLU |
| Pool | MaxPool，2×2，stride=2，padding=0 |
| Upsample | 最近邻 ×2；`out[...,y,x] = in[...,y//2,x//2]` |
| CAT | skip-first，沿 NCHW 的 C 维拼接；两支先转换到共同尺度 |
| 网络宽度 | `base_channels=16`，编码通道 `16→32→64→128` |

没有 BN、转置卷积、残差相加或 3D 卷积。卷积外部补零使用量化值 `0`，空间 tile 的 halo 与整张特征图上的零填充卷积保持一致。

## 4. 15 个卷积层的形状

下表省略 batch=1，尺寸均为 **C×H×W**。C01～C14 都是 3×3 卷积加 ReLU；C15 是 1×1 head。

| 层 | 输入来源 | 输入尺寸 | 输出尺寸 | 保存 / 用途 |
| --- | --- | --- | --- | --- |
| C01 | 三邻层输入 | `3×256×256` | `16×256×256` | 编码 |
| C02 | C01 | `16×256×256` | `16×256×256` | 保存 S0 |
| C03 | P0=MaxPool(C02) | `16×128×128` | `32×128×128` | 编码 |
| C04 | C03 | `32×128×128` | `32×128×128` | 保存 S1 |
| C05 | P1=MaxPool(C04) | `32×64×64` | `64×64×64` | 编码 |
| C06 | C05 | `64×64×64` | `64×64×64` | 保存 S2 |
| C07 | P2=MaxPool(C06) | `64×32×32` | `128×32×32` | 瓶颈 |
| C08 | C07 | `128×32×32` | `128×32×32` | 瓶颈 |
| C09 | CAT1 | `192×64×64` | `64×64×64` | 解码 |
| C10 | C09 | `64×64×64` | `64×64×64` | 解码 |
| C11 | CAT2 | `96×128×128` | `32×128×128` | 解码 |
| C12 | C11 | `32×128×128` | `32×128×128` | 解码 |
| C13 | CAT3 | `48×256×256` | `16×256×256` | 解码 |
| C14 | C13 | `16×256×256` | `16×256×256` | 解码 |
| C15 | C14 | `16×256×256` | `4×256×256` | 无激活输出头 |

各卷积的权重形状为 `[Co,Ci,K,K]`，bias 和 Q24 乘数各为 `[Co]`。

完整前向关系：

```text
X → C01 → C02=S0 → P0 → C03 → C04=S1 → P1
  → C05 → C06=S2 → P2 → C07 → C08

CAT1(S2, C08) → C09 → C10
CAT2(S1, C10) → C11 → C12
CAT3(S0, C12) → C13 → C14 → C15 → head
```

S2 在 CAT1 消费后可释放，S1 在 CAT2 消费后可释放，S0 在 CAT3 消费后可释放。提前复用 skip 缓冲区会改变结果。

## 5. 三处 CAT 的精确语义

```text
CAT(skip, deep) = concat(
    rescale(skip),
    rescale(nearest_upsample_2x(deep)),
    dim=1
)
```

skip 的全部通道放在输出前部，deep 的全部通道放在输出后部。拼接不是两路相加、空间拼接或逐通道交错。

| 节点 | 对应 skip level | skip 分支 | deep 分支，上采样前 | CAT 输出 | Ci | split |
| --- | --- | --- | --- | --- | ---: | ---: |
| CAT1 | 2 | S2：`64×64×64` | C08：`128×32×32` | `192×64×64` | 192 | 64 |
| CAT2 | 1 | S1：`32×128×128` | C10：`64×64×64` | `96×128×128` | 96 | 32 |
| CAT3 | 0 | S0：`16×256×256` | C12：`32×128×128` | `48×256×256` | 48 | 16 |

### 5.1 CAM2 模式约定

沿用现有 CAM2 的模式编号与语义：

| mode | 含义 | 本版调度用途 |
| --- | --- | --- |
| 0 | 卷积，含可选融合 ReLU | C01～C15 |
| 1 | 单张量 LUT 尺度转换 | 兼容现有接口，本版图不要求独立节点 |
| 2 | MaxPool + LUT | P0～P2，使用单位 LUT 保持尺度 |
| 3 | 最近邻 ×2 上采样 + LUT | 兼容现有接口，本版上采样已并入 mode=4 |
| 4 | skip-first CAT + deep 上采样 + 双 LUT | CAT1～CAT3 |

调用 mode=4 时，deep 仍为半分辨率，不能先在 PS 上采样一次后再交给 mode=4。

### 5.2 每个 CAT tile 的配置与字节顺序

```text
mode  = 4
Ci    = Cs + Cd          # Cs 为 skip 通道，Cd 为 deep 通道
split = Cs
Co    = 0
K     = 1
ReLU  = 0
h,w   = Ht,Wt           # skip/output 的 tile 尺寸，不是完整特征图尺寸

skip_tile = [1,Cs,Ht,Wt]
deep_tile = [1,Cd,Ht/2,Wt/2]
output    = [1,Cs+Cd,Ht,Wt]

输入载荷 = skip_tile 的连续 CHW 字节 || deep_tile 的连续 CHW 字节
输入字节 = Cs*Ht*Wt + Cd*(Ht/2)*(Wt/2)
输出字节 = (Cs+Cd)*Ht*Wt
LUT 顺序 = skip LUT 256 B || deep LUT 256 B
```

Ht、Wt 必须为偶数；输出 tile 起点也必须为偶数，以保持全图最近邻上采样坐标对齐。表中的完整张量尺寸不能直接当作单次寄存器配置。

### 5.3 CAT 尺度转换

两个分支各有一个正 INT32 Q24 乘数，分别转换到导出文件规定的同一个 `common_scale`：

```text
q_common = clip(round_even(q_branch * M_branch / 2^24), -127, 127)
```

乘法使用 INT64。两支尺度相等时，单位转换乘数是 `2^24 = 16777216`。无模型预适配可用该乘数验证字节顺序与上采样；真实导出不得假设两支尺度天然相同。

## 6. 卷积数值和参数装载

| 项目 | 规定 |
| --- | --- |
| 权重 | INT8，OIHW 连续排列，值域 `[-127,127]` |
| bias | 每输出通道一个 INT32，小端 |
| 重量化乘数 M | 每输出通道一个正 INT32 Q24，小端，`1≤M≤2^31-1` |
| 完整累加 | `A[o,y,x] = sum(Wq[o,i,ky,kx]*Xq[i,...]) + Bq[o]`，INT32 合法范围内 |
| 重量化 | INT64 乘积 `A*M`，除以 `2^24`，最近偶数舍入，再饱和 |
| 隐藏层 | 重量化结果执行 ReLU，最终值域 `[0,127]` |
| head | 保留负数，值域 `[-127,127]` |

偏置采用与累加器一致的量化单位；完整输入通道累加后仅进行一次重量化，不允许输入通道分块后各自量化再相加。

每个卷积输出通道分块的参数载荷为：

```text
weight[Co_chunk,Ci,K,K] INT8
|| bias[Co_chunk] INT32 little-endian
|| multiplier[Co_chunk] INT32 little-endian

parameter_bytes = Co_chunk*Ci*K*K + 8*Co_chunk
```

权重中的 bias 不预先折入每个 MAC；每个输出累加完成时按定义加入一次。

## 7. 通道分块与 tile 约束

当前 CAM2 每条卷积命令 `Ci≤192`、`Co_chunk≤64`，权重 bank 条件为：

```text
ceil(Co_chunk/8) * ceil(Ci/4) * K*K <= 2048
```

本版按以下输出通道分块适配：

| 卷积层 | 全层 Ci→Co | Co 分块 |
| --- | --- | --- |
| C07 | 64→128 | 64 + 64 |
| C08 | 128→128 | 56 + 56 + 16 |
| C09 | 192→64 | 32 + 32 |

其他层可在通道维单块执行，但空间维仍需分 tile。各块写回原输出通道偏移，例如 C08 写入 `[0:56]`、`[56:112]`、`[112:128]`。

当 Ht/Wt 表示卷积输出 tile、P 为该卷积的 padding 时，还须满足：

```text
ceil(Ci/4) * (Ht+2*P) * (Wt+2*P) <= 32768
ceil(Co_chunk/8) * Ht * Wt <= 8192
```

卷积输入 tile 的高宽不超过 258，输出 tile 的高宽不超过 256。边界 halo 用量化零填充；内部 tile 应取真实相邻特征。

CAT tile 还须满足：

```text
ceil(Cs/4)*Ht*Wt + ceil(Cd/4)*(Ht*Wt/4) <= 32768
ceil((Cs+Cd)/8)*Ht*Wt <= 8192
```

具体 tile 高宽可以在这些约束内优化，不能由此改变完整网络的形状或数值计算。前述规则不代表新 ACDC 驱动和旧 CAMUS 位流已通过兼容性板测。

## 8. 理论静态预算

以下按本文固定结构直接计算，与训练出来的权重数值无关：

| 项目 | 单方向数值 |
| --- | ---: |
| Conv 层数 | 15 |
| INT8 权重元素 | 486,640 |
| bias 元素 | 708 |
| 可训练参数（权重+bias） | 487,348 |
| 裸 INT8 权重 | 486,640 B |
| 权重 + INT32 bias + INT32 Q24 乘数 | 492,304 B，不含 LUT、清单和尺度等元数据 |
| 一次中心层推理的卷积 MAC | 2,674,917,376，不含池化、CAT、搬运等开销 |
| 完整 CAT1 输出 | 786,432 B |
| 完整 CAT2 输出 | 1,572,864 B |
| 完整 CAT3 输出 | 3,145,728 B |

三套裸 INT8 权重合计 1,459,920 B。完整特征图通过 DDR/分块调度管理，不要求全部放入片内 RAM。以上 MAC 和字节数不是板端时延或峰值内存实测。

## 9. 请求与结果的最小元数据

这些元数据用于 PS/PC 任务接口，不混入上述原始输入 tensor 字节中：

| 字段 | 用途 |
| --- | --- |
| `architecture_id` | 必须为 `ACDC25D-B16-P3-v1` |
| `model_id`、模型版本、spec SHA256 | 确定方向、权重和量化参数身份 |
| `run_id`、`volume_id` | 绑定请求与原始患者体数据 |
| `phase` | ED 或 ES |
| `orientation` | axial / coronal / sagittal |
| `center_index`、实际三个邻层索引 | 避免层序错位，记录边界重复 |
| 输入/输出 shape、dtype、layout、字节数 | 检查完整性 |
| `input_scale`、`head_scale`、zero_point | 正确解释量化结果 |
| 原始 affine、spacing 和模型网格到原生网格的变换记录 | PC 拼回体数据；可通过一个几何侧文件引用 |
| 后端、执行状态、分阶段耗时 | 区分真实板端执行、失败和测试桩结果 |

选择方向会同时选择对应的权重、bias、乘数、CAT LUT 和输出尺度。缓存身份必须包含模型版本或 SHA，不能仅依靠输入 shape。

## 10. 无模型联调检查表

以下为联调项目。当前合成生成器已提供固定head、CAT/Q24及C07/C08/C09宽层黄金值；软件参考已验证，物理板端仍需逐项实测。

| 项目 | 无训练模型的验证方式 | 预期 |
| --- | --- | --- |
| 输入输出缓冲区 | 三通道递增/常量输入 | 196,608 B 输入，262,144 B head，NCHW 顺序一致 |
| 全零端到端冒烟 | 全零权重和 bias、正单位 Q24 | 四通道 head 全零；仅作接口冒烟，不能证明每层/每个通道块实际执行 |
| head 符号 | 全零权重，已知正负 head bias，单位 Q24 | 负值保留，证明 C15 未错误执行 ReLU |
| CAT 顺序 | skip 常量，deep 使用可手算的 2×2 递增图案 | skip 通道在前；deep 每个值复制成 2×2 |
| CAT 尺度 | 两路分别使用单位和半倍 Q24 | 独立转换后再拼接 |
| 最近偶数舍入 | `M=2^23`，输入 ±5、±3 | `5→2`、`-5→-2`、`3→2`、`-3→-2` |
| Co 分块 | 为不同输出通道构造可区分参数 | C07/C08/C09 分块写回顺序正确，无覆盖或遗漏 |
| 方向切换 | 三套占位参数使用可区分的 head bias | 切换后输出随 profile 改变，旧参数缓存不串用 |

占位参数必须标记为 synthetic / 非生产工件。测试桩或仿真结果不能标成真实板测，也不能作为模型分割质量证明。

## 11. 已冻结的研究交付与板端待验收项

三套FP32/INT8权重、bias、每层尺度与乘数、三处CAT两路转换参数、各方向head_scale、固定融合权重、黄金输入/head及实际开发验证报告均已冻结，经独立研究Release交付。准确的模型/spec SHA、head_scale和总包校验值见[研究交付索引](RESEARCH_RELEASE.json)。

可以按冻结SHA装载研究模型；合成参数继续只用于接口测试。物理CAM2的bit/HWH配对、实际数值、DDR峰值、故障恢复及性能须独立验收，physical_board_accepted与production_ready仍为false，不伪造硬件配对ID。
