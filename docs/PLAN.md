# PYNQ-Z2 皮肤镜皮损分割阶段计划

## 总体目标（Goal）

基于PYNQ-Z2与ISIC Task 1皮损分割数据，完成“图像输入 → 预处理 → PS/DDR/DMA调度 → PL INT8 TinyUNet推理 → PL后处理与定量分析 → HDMI交互展示”的实时或准实时系统。最终模型采用A的 `role_a_final/soup_v5_a050`（ISIC2016/2017训练与开发口径），旧ISIC2016模型及379图证据保留。用户可连续选图/播放、查看掩膜与叠加、调整阈值或显示参数，并看到实际耗时、推理帧率和面积占比。

**B（本仓库）的核心任务：完成PL加速器及PS交互，向C交付可集成、可复现、可精确验证的计算子系统。**A负责模型/量化/软件参考；B负责RTL、PS7/DDR/DMA、控制与调度、加速器最小BD和数值/性能验证；C负责PL后处理、HDMI/UI及最终系统集成。所有在本仓库执行任务的智能体共同服务于这一目标。

**保留原有阶段0、1、2及其已执行成果，继续关闭剩余验收项，不重新编号或从零开始。**在现有自研工程上演进，优先复用已验证的模块、脚本、测试向量和接口；详细命令与当前证据维护在 `AGENTS.md`、`board/README.md`、`docs/validation/VIVADO_ENVIRONMENT.md`，本文件只规定目标与成功标准。

阶段0/1/2已于2026-09-26按下表验收，证据见[阶段0/1/2验收记录](history/STAGE012_VALIDATION.md)。旧模型的阶段3数值/算子合同和阶段4整网实现、100MHz布线、逐层板测及故障恢复已通过，见[阶段3/4验证记录](history/STAGE34_STATUS.md)。用户于2026-09-27确认C认可现有接口与预算，旧版本阶段3/4验收保留。旧模型 `stage5_ps_range` 已完成379图/1000帧验证，含在线预处理0.636627 FPS，性能尚未达标。

**当前执行用户授权的B最终交付**：默认已切换A最终模型，模型/数据/阈值门禁、软件INT8参考与RTL仿真、真实板卡逐层及故障恢复通过。125 MHz ABI 1.1版本已完成dev638全部638张原JPEG板测和1000帧/≥600秒稳定性门，数值与A逐图一致，但性能未达标。ABI 1.2的最终采用版也已覆盖638张原JPEG、1000帧/1483.827秒、三类故障恢复和独立部署审查，核心1.422 FPS；在线B延迟P95为1.265720秒，尚未达到≤1秒目标。准确版本范围和证据见[最终模型实施进度](FINAL_MODEL_STATUS.md)，初始方案见[最终交付审查](history/ROLE_A_FINAL_REVIEW.md)。

阶段5按B独立子系统验收，无需等待C对接或C确认；C按B实现完成后处理/HDMI/UI。B须交付可复现的控制、数据、结果和恢复合同，并完成最终模型dev638、性能与稳定性验证。用户2026-09-29决定先交付已跑通的[ABI 1.2版本与C调用说明](C_HANDOFF.md)，暂停进一步优化；B在线性能计时到head结果交付，≥1 FPS已达、P95≤1秒仍是未达目标，不能标为已包含C后处理或显示。旧379图为历史回归。

### 各阶段共同遵守的验收口径

- **延续已有工作**：0→1→2的通路成果继续使用；阶段3可在A基线冻结后与通路收尾并行，整网板测使用已经验证的PS/PL通路。已通过结果按版本保留，只有相关代码、参数、接口变化或出现故障时重跑受影响检查。当前完成情况看事实记录，不因重写计划清零，也不因部分用例通过便跳过剩余标准。
- **精确验证**：冻结模型、数据集合、阈值与源码版本，原始head比较mismatch=0。最终包dev638、p=0.45的A软件Dice/IoU为FP32 0.844054368/0.761204057、INT8 0.842050807/0.758341084；当前独立软件/板测状态见 `FINAL_MODEL_STATUS.md`，各集合按各自完成证据验收。旧379图、p=0.50的0.8756/0.7985与0.8724/0.7944保留为旧模型证据，不直接比较优劣。复用第三方模块保留许可并核对合同；软件、RTL仿真、构建、板测分别记录。
- **性能**：医学题目未规定固定FPS；B自定256×256下预热后的有效吞吐≥1帧/秒、在线B延迟P95≤1秒。计时从已解码源RGB进入B预处理直到独立head数组交付，包含预处理、DMA、PL计算、PS调度与结果拷贝；文件读取/JPEG解码、C后处理/显示和物理屏幕刷新另报。各阶段耗时、冷启动/参数复用、测量帧数与并行重叠口径明确；加速段对同口径板载PS CPU运算的加速比>1。C整机集成时再独立报告显示提交延迟与端到端提升，不能用DMA吞吐或HDMI刷新率代替推理帧率。
- **稳定性与交付**：连续运行≥10分钟且≥1000帧，无死锁、错帧、静默数据错误或持续内存增长；受控超时/输入错误/处理中复位后可恢复并算对下一帧。按题目文件，设计文档与视频节点为2026-11-01，现场验收以主办方通知为准；界面及报告声明“仅用于工程教学与算法演示，不作为临床诊断依据”。
