# 双模型网页与 HDMI 四宫格 · 2026-10-16

四个位置固定为：左上原图，右上显示增强，左下分割掩膜，右下轮廓/分割叠加。

- 皮肤镜使用二值掩膜和黄色轮廓；CAMUS使用多结构伪彩掩膜与叠加。
- 增强为 1% 自动对比度，只作用于缩小显示副本，不改变模型输入、标签、面积或原有导出结果。
- 网页保留模型切换、计时、下载和原有 HDMI 控制。皮肤镜先显示已就绪预览，掩膜后台完成后补齐。CAMUS在任务完成时显示四张图。
- HDMI 默认四宫格为 640×480，保留宽高比；英文小标题避免板端缺中文字体。皮肤镜 BTN0/1/2 恢复四宫格，BTN3黑屏。
- HDMI仍按先结束推理、释放硬件，再加载显示位流的方式工作。接线后点击网页显示按钮，不会因插线自动启动输出。
