皮肤镜 ROI 交互分割

先选图并运行，再用点或框修正。网页与 HDMI 触屏共用当前图片和提示；重新选择图片可开始新的一次分割。

在原图上点选或拖框；ROI 为青框，目标框为黄框，前景点绿色、背景点红色。每次新点选或拖框都会清除之前的全部框和点，只保留本次标记。“清除所有标记”清除两种框及全部点，保留图片；点击 Run 重新分割。HDMI 顶部 FG / BG / ROI / Box 选择工具，Run 更新，右下角 Clear all 清除所有标记，Web / Stop 关闭显示。点和框修正使用 CPU；更换 ROI 时先关闭 HDMI 完成 FPGA 推理，再自动恢复显示。
