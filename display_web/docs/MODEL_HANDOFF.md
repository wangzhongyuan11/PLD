# 后续模型升级与接口交接

当前 C 端对接的是 B 的最终 v3 运行包：soup_v5_a050，INT8 输出 `[1,1,256,256]`，原始有符号 logit，共 65536 字节。默认概率阈值 0.45，对应整数 `q >= -1`；补边强制背景。

`pld_result.py` 会严格检查模型/spec/manifest 身份、输出 hash、尺度、阈值、输入图像 hash 和 letterbox 几何。因此同学完成新模型后，不能只把一个新权重文件替换进去。

交接需要：

1. A 与 B 提供新的完整冻结运行包及部署清单，说明输入预处理、量化尺度、阈值、输出形状和模型身份。
2. B 先确认 FPGA 输出与新模型的软件参考一致，并提供真实 JSON/BIN 和对应原始图片。
3. C 更新 `pld_result.py` 的合同检查及样例，必要时更新启动脚本和自启安装器中的运行包路径。若 CLI 参数有变化，同时更新 `infer_then_display.py`。
4. 重新验证掩膜方向、去补边、回映射、面积口径和新图片分割，最后测试网页及 HDMI。

面积在 B 的模型有效网格统计；轮廓在回映射后的原图网格统计。上传掩膜模式则使用上传图网格。边界像素数不是周长，面积百分比不是平方毫米。模型精度与轮廓显示质量应分别评价。

轮廓函数仅根据现有掩膜描边，不改变模型预测。真实板测样例用作程序回归，不代表所有新图像的分割质量。
